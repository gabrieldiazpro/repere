## Les 5 actions les plus efficaces, à faire vous-même
1. **Jour J : Search Console + Bing Webmaster Tools + variables d'entité.** Vérifier le domaine, soumettre le sitemap,
   remplir NEXT_PUBLIC_FOUNDER_* et NEXT_PUBLIC_LEGAL_* (sinon /a-propos reste en noindex et le JSON-LD n'a ni
   fondateur ni sameAs). Sans indexation, rien d'autre ne compte.
2. **Semaine 1 : les profils officiels avec les textes identiques** (LinkedIn entreprise + profil fondateur, Crunchbase,
   G2, Capterra, AlternativeTo), puis leurs URL dans NEXT_PUBLIC_SAME_AS.
3. **Mois 1 : entrer dans les comparatifs francophones qui se classent sur nos questions** (La Fabrique du Net, Codeur,
   Digitiz, comparateur-ia, Appvizer, LeptiDigital, Blog du Modérateur) avec une fiche factuelle et un accès de test —
   sans payer de position non signalée. C'est le levier le mieux étayé : les listes « meilleurs X » sont le premier type
   de page cité par ChatGPT sur les requêtes de comparaison (Ahrefs, déc. 2025).
4. **Mois 1-3 : des mentions gagnées** : proposer la synthèse « pourquoi une IA recommande une marque » à Abondance,
   WebRankInfo, JDN, Blog du Modérateur ; une publication LinkedIn par semaine fondée sur un fait vérifiable ; puis le
   Baromètre en primeur quand il est réel.
5. **Dès les clients pilotes : de vrais avis et la mesure.** Demander un avis G2/Capterra à tous les pilotes (sans tri ni
   contrepartie conditionnelle) ; activer le compte maison et suivre les 30 questions chaque semaine, en notant les
   sources que les IA citent à notre place : c'est la liste des prochains contacts.

Interdits (rappel) : faux avis, faux comptes, votes achetés, texte caché ou consignes aux IA, pages en série,
comparatifs truqués, positions payées non signalées.
