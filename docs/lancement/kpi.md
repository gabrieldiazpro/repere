# Indicateurs à suivre

Un tableau, rempli chaque vendredi. Chaque chiffre a sa source ; si une source n'est pas branchée, la case reste vide
(on n'estime pas). Aucune cible ci-dessous n'est un benchmark : ce sont des points de départ à corriger avec vos mesures.

## 1. Pilotes (source : /admin/pilotes)
| Indicateur | Cible J30 | Alerte |
|---|---|---|
| Candidatures reçues | 30 | < 10 à J10 : élargir le réseau et la prospection |
| Places attribuées (retenue + active) | 10 | < 6 à J15 |
| Répartition local / PME / e-commerce | 4 / 3 / 3 | un parcours à 0 à J15 |
| Pilotes avec J0 mesuré | 10 | J0 manquant > 7 jours après « active » |
| J30 mesurés à temps | 100 % | un jalon « manquant » |
| Délai de réponse aux candidatures | ≤ 5 jours ouvrés | au-delà, le dire à la personne |
| Accords de publication avant/après | — | ne jamais relancer pour l'obtenir |

## 2. Site et produit (sources : statistiques du site, store `analysis.runs`, inscriptions)
| Indicateur | Ce qu'il dit |
|---|---|
| Visites par page d'entrée (/, /pilotes, /barometre/*, /presse) | ce qui attire |
| Analyses gratuites lancées / terminées | intérêt réel et robustesse |
| Taux analyse → inscription (Découverte) | valeur perçue |
| Inscriptions → espace avec 2e mesure | rétention |
| Erreurs d'analyse (sites difficiles) | à corriger en priorité |

## 3. Prospection (sources : outil d'envoi, tableur de suivi)
| Indicateur | Point de départ | Alerte |
|---|---|---|
| Premiers e-mails envoyés / jour | 10 → 25 | — |
| Taux de rebond | < 2 % | > 3 % : nettoyer la liste, arrêter |
| Plaintes pour spam | < 0,1 % | > 0,1 % : arrêt immédiat, revoir ciblage et message |
| Taux de réponse | à mesurer | < 2 % sur 200 envois : changer le message, pas le volume |
| Réponses positives → appel | à mesurer | — |
| Désinscriptions traitées sous 24 h | 100 % | toute exception |
| Appels : joints / intéressés | à mesurer | — |

## 5. Revue du vendredi (20 minutes)
1. Remplir le tableau.
2. Une chose qui marche : on la double la semaine suivante.
3. Une chose qui ne marche pas : on l'arrête ou on la change, pas les deux.
4. Une remarque de pilote transformée en tâche produit.
